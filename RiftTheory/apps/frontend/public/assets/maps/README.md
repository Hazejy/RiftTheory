# Map asset note

`summoners-rift.jpg` is a temporary development asset extracted from the
RiftKit planner reference supplied during product prototyping. The underlying
Summoner's Rift artwork is owned by Riot Games.

Before a public RiftTheory release, replace this temporary file through the
project's approved Riot asset pipeline and review the current Riot developer
and "Legal Jibber Jabber" policies. Planner coordinates and overlays are kept
independent from the image so the map can be replaced without migrating plans.
