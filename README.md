# RiftTheory

RiftTheory is a League of Legends draft and coaching tool built to make drafting easier and more structured.

The goal is to help players and coaches analyze team compositions, prepare drafts, and make better decisions during champion select.

The project is still in development and new features will be added over time.

## Download

Open the [latest RiftTheory release](https://github.com/Hazejy/RiftTheory/releases/latest) and download the Windows file ending in `x64-setup.exe`.

The MSI package and old command-file launchers are intentionally not published. They are not needed to install or run the desktop application.
